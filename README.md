# Fábrica de Animaciones · nube

Vídeos animados 2D (estilo «Archivo») de punta a punta desde Claude en la nube, con la voz automática de ElevenLabs.
Instrucciones para Claude: `CLAUDE.md` y `skill/animaciones-nube/SKILL.md`.

Necesita en el entorno de la nube:
- Variable `ELEVENLABS_API_KEY` (la clave de ElevenLabs).
- Dominio `api.elevenlabs.io` permitido en el acceso de red.
